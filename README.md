This repository includes a GitHub Actions workflow at:

It deploys the static site to GitHub Pages from the `main` branch when GitHub Pages is configured for GitHub Actions.

Deployment and fallback instructions are maintained in:

`README_DEPLOY.md`

Current status and expected product paths are maintained in:
